# L1 — Async Resilience（弱网 / 重试 / 超时）

## 适用信号

超时、重试、乐观更新、离线提示、重复提交、幂等。

---

## 标准解法

### 1. 超时

客户端超时与用户可感知取消；区分「Abort」与「业务错误」。

### 2. 重试

仅幂等读或明确可重试写；指数退避 + 抖动；限制次数；写操作优先幂等键。

### 3. 乐观更新

UI 先变 → 失败回滚 → 提示；冲突时以服务端为准并刷新。

### 4. 重复提交

见 [form-input.md](form-input.md)；支付类必须服务端幂等。

---

## 反模式

```ts
// ❌ while(true) 无退避狂重试打爆后端
// ❌ POST 创建订单失败自动重试 5 次 → 多单
// ❌ 乐观更新失败不回滚
```
